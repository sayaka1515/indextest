# Water Puzzle Game

## 遊戲介紹
Water Puzzle 是一款益智遊戲，玩家需要將試管中的水按照顏色分類，直到每個試管中的水都是同一種顏色。

---

## 遊戲設定
1. **關卡選擇**：
   - 玩家可以從下拉選單中選擇關卡（1 至 10）。
   - 如果從第一關開始並逐關挑戰，將被視為「完整通關模式」。

2. **完整通關模式**：
   - 玩家從第一關開始，逐關挑戰到第十關，完成後會顯示「您已經全部通關，恭喜！」的提示。
   - 如果直接選擇第十關並完成，則顯示「你已經完成本關卡！」。

3. **試管設定**：
   - 每個關卡的試管數量會根據關卡數量增加。
   - 顏色的數量與關卡數量相同，每種顏色的水會隨機分布在試管中。

4. **存檔與讀檔**：
   - **存檔**：玩家可以隨時存檔，存檔會記錄當前關卡、試管狀態以及是否為完整通關模式。
   - **讀檔**：讀取存檔後，遊戲會恢復到存檔時的狀態，包括試管內容和完整通關模式的設定。

5. **通關條件**：
   - 當所有試管中的水都按照顏色分類完成，或試管為空時，視為通關。

---

## 操作方式
1. **選擇試管**：
   - 點擊試管以選擇，然後點擊另一個試管將水倒入。
   - 水只能倒入空試管或顏色相同的試管，且試管最多容納 4 層水。

2. **按鈕功能**：
   - **PLAY**：開始當前選擇的關卡。
   - **存檔**：將當前遊戲進度存為 JSON 檔案。
   - **讀取檔案**：從 JSON 檔案中讀取遊戲進度。

---

## 注意事項
1. **完整通關模式**：
   - 如果在遊戲過程中跳關或直接選擇第十關，將不再視為完整通關模式。

2. **存檔格式**：
   - 存檔檔案名稱格式為 `waterpzXX.json`，其中 `XX` 為關卡數字。

3. **讀檔限制**：
   - 請確保讀取的檔案為正確的遊戲存檔格式，否則可能導致讀檔失敗。
